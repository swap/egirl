# egirl v2

A minimalistic portfolio website, free to download, use, and modify. v1 was disbanded this is the replacement.

Licensed under [MIT](LICENSE). Updates will be committed here as the project grows. I will not provide support or maintain custom use cases or accept contributions, as this is my personal project and portfolio.

## tools

### music

Live “now playing” and lyrics:

- **Spotify API** — current track, progress, play/pause
- **[Musixmatch](https://www.musixmatch.com/)** — synced lyrics (word-level when available)
- **spdrm** — downloads the Spotify track as ogg for local streaming with the lyrics


## Getting started

1. install [bun](https://bun.sh/)
2. rename `.env.example` to `.env`and add the variables
3. run:

```bash     
bun install
bun dev # bun build > bun start for production
```

Open at [localhost:2000](http://localhost:2000).
